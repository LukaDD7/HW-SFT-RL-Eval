# Coordinator: create the five midterm Issues in a browser

不需要 API token 或设备授权码。协调者在已登录 GitHub 的浏览器中完成以下步骤；
打开链接只会生成草稿，点击 **Submit new issue** 才会创建 Issue。

1. 先打开 [Issues 列表](https://github.com/LukaDD7/HW-SFT-RL-Eval/issues)，确认没有相同 `[Midterm][T<N>]` 前缀的任务。
2. 依次点击下面五个预填链接，核对标题和正文后分别点 **Submit new issue**。不要改标题前缀，暂时不需要指定 assignee。
3. 把五个新 Issue 链接发给协调维护者，回写到本目录 `README.md`；也可以直接提交更新链接的 PR。
4. 团队成员按会议分工自行 assign，并按正文和统一验收合同登记开工信息。
